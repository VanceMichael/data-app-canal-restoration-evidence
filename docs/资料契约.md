# 资料契约

所有记录均为本地合成演练资料，不含真实个人、企业或医疗信息。文件使用 UTF-8 JSON，金额和数量以各字段说明为准。空串、零、缺报、争议分别保留其含义，不可互相替换。

记录的 `id` 只在本资料类别内唯一。`known`、`known_day`、`known_week`、`known_month` 表示收到事实的时间；实际发生时间另有字段。日序和分钟是演练的相对时间，未另行说明的区间均左闭右开。月份为演练年度的自然月。

`data/schema.json` 声明字段、类型和显式引用。数组与对象内的业务关系按相应中文字段说明解释；资料检查器不替代这些业务关系的判断。原始与后补记录共存，文件排列不代表业务生效顺序。

## projects

修复空间、期间及工程量。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 项目 |
| `reach` | string | 河段 |
| `start_day` | integer | 开工 |
| `deadline` | integer | 期限 |
| `physical_work` | string | 可结工程量单位 |
| `contract_cents` | integer | 合同金额 |
| `retain_fraction` | number | 保留比例 |

## promises

独立成效承诺允许的证据。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 承诺 |
| `project` | string | 项目 |
| `domain` | string | 水质或生境或景观 |
| `target` | string | 目标状态 |
| `allowed` | array | 证据类别 |
| `deadline` | integer | 期限 |

显式引用：`project` → `projects.id`。

## measurements

左删失检出限和复测标识；未置入成效答案。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 读数 |
| `sample` | string | 独立样品 |
| `station` | string | 站点 |
| `day` | integer | 采样日 |
| `flow_class` | string | 水文 |
| `value` | number | 毫克每升读值 |
| `lod` | number | 检出限 |
| `censored` | boolean | 低于限 |
| `design` | string | 计划或定向 |
| `known_day` | integer | 结果知悉日 |

显式引用：`station` → `stations.id`。
